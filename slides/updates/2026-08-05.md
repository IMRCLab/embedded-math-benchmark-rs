## Headline: Rust vs the actual C reference

- First data against Crazyflie's real C math (`math3d.h`), not just `libm`
- STM32, several ops: Rust beats the C reference outright
  - SinCos: `micromath` **~29x faster** than the C reference
  - QuatSlerp: `micromath` **~15x faster** than the C reference
  - MatMul3x3: `glam`/`nalgebra` **~2x faster** than the C reference

## New task: LeeController

- First **full controller**, not an isolated math primitive
- host: sub-microsecond, converges across libraries (~0.08 us)
- rp2350-arm / stm32: **5-16 us**, depending on library
- rp2040 (Pico 1): **~455 us** (no hardware FPU)
